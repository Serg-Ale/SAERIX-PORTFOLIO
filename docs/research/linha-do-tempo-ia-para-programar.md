Legenda de confiança: CONFIRMADO (fonte primária lida), PARCIAL (fonte indireta ou só parte do fato em fonte primária), NÃO ENCONTRADO (sem fonte primária).
Fontes "secundárias" estão marcadas como tal e valem só como pista.
Datas da API do GitHub (criação de repositório, releases, commits) foram lidas com `gh api` em 2026-10-15.

## 1. Resumo

- A ordem geral da história do autor se sustenta: ChatGPT (nov/2022) vem antes do Claude Code (fev/2025), que vem antes de Codex CLI (abr/2025) e Gemini CLI (jun/2025). Os pontos fracos são o Copilot e o OpenCode, detalhados na seção 3.
- O Copilot já existia antes do ChatGPT (preview em jun/2021, GA em jun/2022). O modo agente, que roda comandos, lê o erro e corrige em loop, chegou em fev/2025 (Insiders) e abr/2025 (VS Code estável). O Claude Code CLI saiu na mesma época (24/fev/2025), então "Copilot agente, depois Claude Code" é quase simultâneo, não uma sequência clara.
- O Claude Code foi lançado como CLI de terminal, não como extensão do VS Code. A extensão nativa do VS Code veio em beta em 29/set/2025. Uma extensão anterior de "um arquivo por vez" não aparece nas fontes primárias; vale checar de qual produto o autor fala (ver seção 3, item 5).
- "OpenCode nerfado pelas outras empresas" é imprecisa. Só a Anthropic agiu: atualizou a política em fev/2026, passou a cobrar uso de harnesses de terceiros à parte em 4/abr/2026, e o OpenCode removeu o plugin de login Claude Pro/Max em 19/mar/2026 após "pedidos legais". A OpenAI, ao contrário, passou a permitir login ChatGPT Plus/Pro no OpenCode (documentação do OpenCode).
- Sisyphus é o agente orquestrador principal do plugin oh-my-opencode (hoje oh-my-openagent), do usuário `code-yeongyu`. Ralph é uma técnica de Geoffrey Huntley (post de 14/jul/2025). OpenClaw é um projeto de Peter Steinberger (repo criado em 24/nov/2025, nome original Clawdbot). Ralph e OpenClaw não "nasceram" depois do OpenCode: Ralph é de jul/2025 e OpenClaw de nov/2025, ou seja, ambos antes do bloqueio da Anthropic.
- Cobrança: houve migração geral de preço fixo para uso medido. O Copilot trocou "premium requests" por créditos baseados em tokens em 1/jun/2026. A Anthropic criou o plano Max (abr/2025, PARCIAL), limites semanais (ago/2025, PARCIAL) e cobrança extra para harnesses de terceiros (abr/2026, PARCIAL).
- Não encontrei fonte primária legível para: o texto do anúncio original do ChatGPT (openai.com devolve 403), "boom no Brasil" do ChatGPT (só há estatística de IA generativa em geral, TIC Domicílios 2025), a data em que o Claude Code entrou no plano Pro, e o comunicado oficial da Anthropic sobre a cobrança de 4/abr/2026.
